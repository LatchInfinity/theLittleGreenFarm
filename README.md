# The Little Green Farm

A private farmhouse stay near Bangalore for slow weekends, shared plans, retreats, workshops, shoots, and simple time in nature.

The Little Green Farm website is a Vite + React single-page experience that presents the farm as a quiet escape from Bengaluru. It highlights the private farmhouse, open green spaces, farm animals, guest reviews, booking prompts, and stories from the farm.

## Highlights

- Private farmhouse booking experience
- Farm-stay sections for families, friends, retreats, workshops, shoots, and celebrations
- Responsive React frontend styled with Tailwind CSS
- Image-led landing page with local farm assets
- Lightweight static build generated through Vite

## Tech Stack

- React 18
- Vite 6
- Tailwind CSS 3
- Lucide React icons

## Getting Started

Install dependencies:

```bash
npm install
```

Run the local development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

## Project Structure

```text
assets/images/   Site images and logo
src/App.jsx      Main page sections and content
src/index.css    Tailwind and global styles
src/main.jsx     React entry point
```

## Brand

The site is built around a simple promise: Bengaluru, but without the noise. It invites guests to slow down, step outside, and enjoy a private green space made for unhurried time together.
